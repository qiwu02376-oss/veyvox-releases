Veyvox 0.4.2 beta.1 — Apple Silicon Mac 测试版

1. 将 Veyvox.app 拖到 Applications（应用程序），再从应用程序打开。
2. 打开「配置指引」，在 AI Engine 中依次安装 Moonshine 和 Qwen3，合计约 3 GB；Whisper 可选。
3. 下载完成后点击「检测本地模型」。检测通过后允许麦克风并开始翻译。

无需终端、Python、Node、单独安装 Ollama 或 API Key。首次下载模型需要联网；下载后识别和翻译在本机运行。建议 16 GB 或更多内存，至少预留 8 GB 可用磁盘空间；8 GB 内存机器尚未验证。

仅适用于 Apple Silicon（M 系列）Mac。构建目标 macOS 15+，实测为 macOS 27.0.1；macOS 15/26 尚未实机验证。不支持 Intel Mac、Windows 或手机。

这是未经过 Apple Developer ID 签名与公证的测试版。若 macOS 提示无法验证开发者，确认文件来自官方仓库后，按 Apple 官方说明在「系统设置 → 隐私与安全性」选择「仍要打开」。不要关闭系统安全保护。
https://support.apple.com/102445

0.4.2 修复了运行后 Python 缓存改变应用内容的问题，调整了打包流程，并校验生成的 DMG 内应用签名。请用此版替代 0.4.1 beta.1。

自动测试使用合成语音，不能代表真实教室准确率。远场、噪声和多人讲话仍可能造成漏词、误译或延迟。第一次加载模型较慢；下载失败可取消或重试。

关闭窗口会保留后台服务；完全退出请使用菜单「退出 Veyvox」。旧浏览器记录不会自动导入。

下载与反馈：https://github.com/qiwu02376-oss/veyvox-releases/releases
